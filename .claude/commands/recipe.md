`.claude/skills/recipe/SKILL.md` 의 워크플로우를 그대로 실행해줘.

**사용자 입력**: $ARGUMENTS

## 실행 절차

1. **인벤토리 로드** — `python3 .claude/skills/recipe/scripts/inventory.py` 실행해서 현재 재료 + 유통기한 임박 상태 확인.

2. **분기 처리**:
   - 입력이 비어 있음 → 추천 후보 3~5개 제시 (사용자 프로필 제약 준수: 2인분 / 20분 이내 / 초급자 친화 / 만족도 높음, 임박 재료 우선) → 사용자에게 어떤 거 만들지 물어보기
   - 입력이 `임박` 또는 `유통기한` → D-7 이내 재료 우선으로 추천 후보 제시
   - 입력이 특정 레시피명 → 곧바로 해당 레시피 상세 생성으로 진행

3. **상세 레시피 생성** — 사용자가 선택했거나 곧바로 지정한 레시피에 대해, SKILL.md 의 "레시피 출력 포맷" (YAML 프론트매터 + 본문) 에 맞춰 마크다운 작성.

4. **파일 저장** — `Write` 도구로 다음 위치에 저장:
   - 디렉토리: `/Users/henrykim/Downloads/HARBOR/test-01/week-4/레시피앱/recipe/`
   - 파일명: `YYYY-MM-DD-<슬러그>.md` (공백→`-`, 동일 파일 존재 시 `-2`, `-3` 부여)
   - 저장 후 사용자에게 "✅ 저장됨: <전체경로>" 한 줄로 알림

## 제약 (사용자 프로필)

- 인분: 2인분 기본
- 조리 시간: 20분 이내
- 난이도: 초급자 친화 (★★☆ 이하), 단 만족도 높은 검증된 가정식
- 사용자가 명시적으로 다른 값을 요청한 경우에만 재정의

자세한 추천 우선순위, 레시피 풀, 출력 포맷은 `.claude/skills/recipe/SKILL.md` 참고.
