01 — Layout

Flexbox Code

핵심 CSS 속성 3가지만 기억하세요

/* 부모 컨테이너 */
.container {
  display: flex;
  gap: 16px;
  justify-content: center;
  flex-wrap: wrap;
}

/* 자식 요소 */
.box {
  width: 140px;
  height: 140px;
  border-radius: 12px;
}

02 — Layout

Grid Code

auto-fit + minmax로 반응형 그리드 완성

.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(200px, 1fr));
  gap: 20px;
}

.card {
  border-radius: 16px;
  padding: 24px;
  border: 1px solid #ccc;
  transition: border-color 0.3s;
}

04 — Components

Form Code

:focus 상태의 border-color로 인터랙션 피드백

input, select {
  width: 100%;
  padding: 12px 16px;
  background: #2c2c2e;
  border: 1px solid #3a3a3c;
  border-radius: 12px;
  outline: none;
  transition: border-color 0.2s;
}

input:focus {
  border-color: #2997ff;
}

Animation Code

animation 속성 하나로 무한 반복 모션

  animation: bounce 1s infinite;
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-30px); }
}

.gradient-text {
  background: linear-gradient(90deg, pink, blue);
  background-size: 200%;
  -webkit-background-clip: text;

}
